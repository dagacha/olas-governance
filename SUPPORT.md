# Support

Use [GitHub Issues](https://github.com/dagacha/olas-governance/issues) for reproducible bugs and feature requests. Include the command used, sanitized output, operating system, Python version, and relevant non-secret configuration.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This repository monitors governance activity; it does not provide investment, legal, or voting advice.
